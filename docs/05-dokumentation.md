# Dokumentation (Wissenssammlung)

Jeder Bereich (Werkstatt, Büro, IT) hat eine eigene Wissenssammlung für Arbeitsanweisungen, Checklisten, Abläufe, Vorlagen und
Betriebswissen. Sie steht im jeweiligen Bereich der Navigation unter **Dokumentation**. Wer lesen darf und wer schreiben darf,
legen die Rollen fest.

## Seiten lesen und finden

* Die Seiten sind in **Kategorien** gegliedert; oben gibt es eine **Suche** über Titel und Inhalt.
* Lange Seiten haben ein **Inhaltsverzeichnis**.
* Wichtige Seiten lassen sich **anheften**: Sie erscheinen dann auf der Übersicht.

## Seiten schreiben

Seiten werden in **Markdown** geschrieben, einer einfachen Auszeichnung. Der Editor hat eine Werkzeugleiste und eine
**Live-Vorschau**.

| Wunsch | Schreibweise |
| --- | --- |
| Überschrift | `## Überschrift` (zwei Rauten), Unterüberschrift `### …` |
| **fett**, *kursiv* | `**fett**`, `*kursiv*` |
| Aufzählung | `- Punkt` |
| Aufgabenliste | `- [ ] offen`, `- [x] erledigt` |
| Link | `[Text](https://…)` |
| Tabelle | Spalten mit senkrechtem Strich trennen, zweite Zeile mit `---` |
| Zitat | `> Hinweis` |
| Code | `` `Code` `` oder ein Block zwischen drei Gravis-Zeichen |

Rohes HTML wird nicht ausgegeben (aus Sicherheitsgründen).

* **Bilder:** Per Knopf hochladen oder aus der Zwischenablage einfügen (PNG, JPEG, WebP oder GIF, bis 2 MB). Bilder sehen nur
  Personen, die den Bereich lesen dürfen.
* **Adresse einer Seite:** Sie bleibt stabil, auch wenn der Titel später geändert wird – Links auf die Seite bleiben gültig.

## Versionsverlauf

Jede Speicherung legt eine Version an (die letzten 30 je Seite bleiben erhalten). Im **Verlauf** lässt sich eine ältere Fassung
ansehen und mit einem Klick wiederherstellen.
