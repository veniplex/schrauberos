# Seiten schreiben (Markdown)

Das **Handbuch** und die **IT-Dokumentation** bestehen aus Seiten, die in **Markdown** geschrieben werden, einer einfachen
Auszeichnung. Der Editor hat eine Werkzeugleiste und eine **Vorschau**.

| Wunsch | Schreibweise |
| --- | --- |
| Überschrift | `## Überschrift` (zwei Rauten), Unterüberschrift `### …` |
| **fett**, *kursiv* | `**fett**`, `*kursiv*` |
| Aufzählung | `- Punkt` |
| Aufgabenliste | `- [ ] offen`, `- [x] erledigt` |
| Link | `[Text](https://…)` |
| Tabelle | Spalten mit senkrechtem Strich trennen, zweite Zeile mit `---` |
| Zitat | `> Hinweis` |
| Code | `` `Code` `` oder ein Block zwischen drei Gravis-Zeichen |

Rohes HTML wird nicht ausgegeben (aus Sicherheitsgründen).

## Bilder

Bilder lassen sich per Knopf hochladen oder aus der Zwischenablage einfügen (PNG, JPEG, WebP oder GIF, bis 2 MB). Bilder sehen
nur Personen, die die jeweilige Dokumentation lesen dürfen.

## Adresse und Versionsverlauf

* **Adresse einer Seite:** Sie bleibt stabil, auch wenn der Titel später geändert wird – Links auf die Seite bleiben gültig.
* **Versionsverlauf:** Jede Speicherung legt eine Version an (die letzten 30 je Seite bleiben erhalten). Im **Verlauf** lässt sich
  eine ältere Fassung ansehen und mit einem Klick wiederherstellen.
* **Gleichzeitig bearbeiten:** Speichern zwei Personen dieselbe Seite nacheinander, bekommt die zweite einen Hinweis und
  überschreibt nichts.
